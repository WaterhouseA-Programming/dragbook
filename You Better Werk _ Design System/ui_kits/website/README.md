# DragBook — Website UI Kit

Full interactive prototype of the DragBook website (4 screens).

## Screens
- **Homepage** (`/`) — Hero + search + performer grid + how it works + testimonials + CTA
- **Browse** (`/browse`) — Filtered performer grid with sidebar facets
- **Profile** (`/profile`) — Individual performer page with booking widget + tabs
- **Pricing** (`/pricing`) — Plan comparison + commission explainer + FAQ

## Usage
Open `index.html` in a browser. Click nav links and cards to navigate between screens.

## Design Notes
- Fonts: Abril Fatface (display), Playfair Display (headings), DM Sans (body)
- All Google Fonts — no local files needed
- Glitter canvas animation runs on every page
- Custom cursor (ring + dot) active on desktop
- Colors: see `colors_and_type.css` in root
